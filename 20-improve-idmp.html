Task 3B(ii) Improvements (website)

Explain how you could improve your website.

Navigation improvements Interactivity improvements Usability improvements
Do not just say "make it better":
Explain exactly what would change and how that improves effectiveness.

Website improvements (examples)

  • Improve navigation labels (clearer, audience-friendly language).
  • Add a search/filter if the site has lots of content.
  • Add better user feedback (success messages, progress, scores).
  • Improve mobile layout (bigger buttons, less clutter).
  • Reduce cognitive load (shorter sections, more headings, more white space).

Common high-mark improvements

  • Accessibility mode (larger text toggle / high contrast).
  • Consistency: reusable components across pages.
  • Better content hierarchy: hero → key points → detail → action.
  • More robust testing and bug fixes.
