Task 3B(i) Improvements (assets)

Recommend how you could improve the assets used.

Specific improvements Link to problem Explain impact
Use real numbers:
e.g., reduce hero image from 2.8MB to ~250KB or resize to 1600×900.

Improvements to assets (examples)

  • Replace low-quality images with higher-quality originals.
  • Create a more consistent icon set (same style/size).
  • Improve readability (higher contrast, simpler diagrams).
  • Compress large images without losing important detail.
  • Add alternative text for key images (accessibility).

How to write it

  • Identify the issue (what is wrong).
  • Explain the improvement (what you would change).
  • Explain the benefit (how it helps client/audience).
  • Explain how you would do it (tools/steps).
