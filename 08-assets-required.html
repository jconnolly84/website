Task 1C(i) Assets required

Identify assets you need, where they come from, and why you need them.

List all assets Explain source Explain purpose
Template:
Asset list + properties template

Assets to identify

  • Images (logos, icons, photos, diagrams).
  • Graphics (SVGs, illustrations, backgrounds).
  • Media (audio/video if used).
  • Text content (headings, body text, FAQs).
  • Interactive assets (buttons, UI components, code snippets).

Explain planned use (OCR wants 'where, how, why')

  • Where will it appear? (page + section)
  • How will it help the user? (attention, clarity, navigation)
  • Why this asset type? (SVG for scalability, JPG for photos, etc.)
  • Source + licensing (own work / copyright-free / client provided).
