Task 1A(iii) Content ideas

Plan what pages/sections/content your website will include.

Plan pages + content Use headings + sections Keep it audience-friendly
Quick win:
Use a repeating page layout: hero title → what to do → example → mistakes. Consistency is professional.

Content planning evidence

  • A site map (pages and how they link).
  • For each page: purpose + what content it contains (headings, images, text, embeds).
  • Key messages (what users should learn/do).
  • Any downloads/links you will provide (with file names).

Common misses

  • Forgetting a clear home page with purpose and navigation.
  • No calls-to-action (what the user should do next).
  • Too much text (no chunking, no headings, no visuals).
  • Planning content that you cannot realistically create in time.
